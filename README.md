# 声序 · 2026年度百首

网站：https://echoslowxu.github.io/sonic-year-2026/

导入网易云歌单，随机抽歌、拖拽排名，选出你的年度100首。支持歌手分类统计、淘汰区、撤销和备份。

## 数据与隐私

每个浏览器独立保存榜单。仓库只包含网页程序与演示歌曲，不包含任何人的私人排名。

旧网址的排名不会自动跨域同步：在原网站点击“导出榜单 → 导出完整备份”，再在此网站点击“导入歌单 → 文件 / 文本”，选择 JSON 备份，勾选替换后恢复。

## 部署

GitHub Pages 从 main 分支根目录发布。index.html 已内嵌所需样式和脚本，无需安装依赖。网易云歌单链接导入使用现有公开服务；接口受限时，可使用文本、CSV 或 JSON 导入。
