# 声序 · 2026 年度百首

网站：https://echoslowxu.github.io/sonic-year-2026/

从网易云歌单选出自己的年度 100 首，支持随机抽歌、拖动排名、歌手统计和淘汰区。

## 本次更新

- 浅色 PDF 榜单：预览、自动换行、A4 分页与直接下载，替换原 CSV 导出。
- 完整 JSON 备份与恢复继续保留。
- 网易云短链和整段分享文字继续通过 GoMusic 读取，B 站搜索试听保持可用。
- 不需要账号、用户名或密码，不添加云端用户功能。

## 你的进度

仍使用原来的浏览器保存键 sonic-year-2026-v1，网站更新不会清空、迁移或覆盖旧进度。使用原来的浏览器打开同一网址，即可继续排序。

本地数据不会自动跨设备或跨网址同步。更换设备、使用无痕窗口或清理浏览器后，请通过完整 JSON 备份恢复；建议定期导出备份。

仓库只包含网页程序与演示歌曲，不包含任何人的私人排名。网易云导入仅向 sss.unmeta.cn 发送歌单链接，不上传本地排名，也不连接 chatgpt.site。第三方接口可能波动，失败时不会覆盖现有进度。
